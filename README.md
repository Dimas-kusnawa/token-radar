Token Radar (model radar-2) ranks every pre-token protocol in the sealed DefiLlama snapshot by implied value — TVL, seven-day growth, age with no token, chain breadth, and an early boost for young protocols — and gives each one a concrete farm plan. The dashboard is a static, no-network page with a ranked board, a detail view per protocol, and filters by category, chain and signal.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
